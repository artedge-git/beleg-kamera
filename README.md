# Beleg-Kamera

book|desk · artedge: Kassenzettel mit dem iPhone fotografieren, automatisch zuschneiden
(lange Zettel in mehreren Stücken, Überlappung wird entfernt) und direkt in den
Dropbox-Ordner `/_artedge eU/bookdesk/_Eingang` laden.

Läuft komplett im Browser (GitHub Pages), ohne Server. Der Dropbox-App-Schlüssel in
`config.js` ist öffentlich und ohne Geheimnis (OAuth PKCE).
